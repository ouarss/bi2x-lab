Reading the knobs

Each knob shows three numbers: the raw 16-bit position, the same position on the 0 – 1023 scale a check screen displays, and the revolutions travelled since this page connected.

One revolution is one full range. The counter wraps once per turn, which is why a reader has to sample fast: sample slowly and half a turn looks like half a turn backwards, since nothing distinguishes the two. Measured by counting wraps over five slow revolutions: 65357 counts each, within 0.3 % of 65536.

Turn a knob exactly five times and watch the revolution count: if it does not read 5, the reading is losing motion, and no amount of scaling downstream will put it back.

      Reading the inputs

      board → host

      The board never speaks first. The host asks, the board answers. Five steps turn the answer into buttons and knobs. Each step explains the output of the step before it.

      1Poll

      You send a short request. The board answers with the WHOLE panel at once: all buttons and both knobs, 17 samples deep. There is no per-input request.

      2The frame

      Every message, either way (a request you send or an answer the board returns), is one frame: AA | node | tag | size | flags | payload | crc7. The size is a varint: one or two bytes.

      header on the wire AA03D7C1 6A5D

      3Unscramble

      The payload arrives scrambled by a small reversible generator seeded from the frame's tag.
      One reversible step turns it back to plain bytes. A byte whose odd bits are all set (like FF) passes through unchanged.

      the same nine bytes, both sides of the pass 70 11 2C 2E 4F 5C 64 3A 17 03 21 05 00 00 00 01 00 7C

      4Block and records

      The plain payload is a 7-byte block header, then 17 records. Each record is the full panel at one instant: 7 bytes of digital inputs + 6 bytes of analog.

      block header, then record 0 D6 00 00 00 00 00 00 FF FF FF FF FF 7F FF| 84 51 FA 00 20 03

      5Meaning

      The 7 digital bytes are 56 input bits; a button is active LOW (bit 0 = pressed). The 6 analog bytes are four 12-bit channels widened to 16 bits: VOL-L and VOL-R (two are unused). A knob is an absolute counter that wraps once per turn, so you read the wrapped difference between two samples.

      record 0, read out FF FF FF FF FF 7F FF

      → no button pressed (a pressed button pulls its bit to 0).

      84 51 FA 00 20 03

      → VOL-L = 33880 (529 on the 0..1023 scale) · VOL-R = 8097 (126 / 1023).

      Wrap: old = 65500, new = 40 → the move is +76, not −65460. Always read the wrapped difference between two samples.

      Driving the outputs

      host → board

      One command paints the LED strips, one command sets the button lamps. Both travel the same road: pack, scramble, frame, send.

      1Choose the command

      03 21 (SetTapeLedData) paints a LED strip; one pixel is a 15-bit 5-5-5 RGB colour. 03 11 (SetOutputs) sets the button lamps, which ride inside the poll frame.

      LED command, plain payload 03 21050000 000300 7C 00 7C 00 7C
      lamp command, plain payload, 48 bytes 03 11FF00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00FF00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 0003 10

      2Pack

      The payload is packed with a small sliding-window scheme: a compact encoding the board unpacks on its side. The 13-byte LED payload above packs into 9 bytes.

      3Scramble + checksum

      The packed bytes are scrambled with the same tag-seeded generator, and a 7-bit checksum of the PLAIN payload is appended and scrambled with them.

      LED example: packed + crc7, scrambled for the wire 7B 33 08 2B BC 5C 19 3B 33 34

      4Frame it

      Wrap as AA | node=02 | tag | size | flags | payload | crc7. The flags byte carries a 4-bit header checksum.

      the LED command on the wire: strip 5, 3 red pixels AA02370D907B 33 08 2B BC 5C 19 3B 33 3407

      5Send

      The board unpacks the frame and lights the LED or the lamp.

      step

      Turn each volume slowly through a full revolution: the needle should sweep 360° without jumping, and the other volume must stay still.
